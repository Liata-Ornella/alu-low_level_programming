# C - Recursion

This project introduces recursion in C programming.

## Learning Objectives

- Understand recursion.
- Implement recursive functions.
- Identify when recursion is appropriate.
- Understand when recursion should be avoided.

## Tasks

| File | Description |
|---|---|
| 0-puts_recursion.c | Prints a string followed by a new line |
| 1-print_rev_recursion.c | Prints a string in reverse |
| 2-strlen_recursion.c | Returns the length of a string |
| 3-factorial.c | Calculates the factorial of an integer |
| 4-pow_recursion.c | Calculates a number raised to a power |
| 5-sqrt_recursion.c | Finds the natural square root |
| 6-is_prime_number.c | Checks whether an integer is prime |

## Requirements

- Ubuntu 20.04 LTS
- GCC
- Betty coding style
- No loops
- No global variables
- No static variables
- No standard library functions in the submitted implementations
- Function prototypes declared in main.h
