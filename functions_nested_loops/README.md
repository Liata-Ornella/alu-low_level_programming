# C - Functions, Nested Loops

## Description

This project contains C programs demonstrating functions, nested loops, conditional statements, character printing, and arithmetic operations.

## Learning Objectives

- Understand function declarations and definitions.
- Use nested loops to repeat operations.
- Work with characters and integers.
- Apply conditional statements.
- Print formatted output using `_putchar`.
- Compile C programs using GCC.

## Files

- `0-putchar.c` — Prints `_putchar`.
- `1-alphabet.c` — Prints the lowercase alphabet.
- `2-print_alphabet_x10.c` — Prints the alphabet ten times.
- `3-islower.c` — Checks whether a character is lowercase.
- `4-isalpha.c` — Checks whether a character is an alphabet letter.
- `5-sign.c` — Prints and returns the sign of a number.
- `6-abs.c` — Calculates the absolute value of an integer.
- `7-print_last_digit.c` — Prints and returns the last digit.
- `8-24_hours.c` — Prints every minute of the day.
- `9-times_table.c` — Prints the multiplication table from 0 to 9.
- `10-add.c` — Adds two integers.
- `11-print_to_98.c` — Prints numbers from a given integer to 98.
- `main.h` — Contains function prototypes.

## Compilation

Programs are checked using:

`gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
