# C - malloc, free

This project introduces dynamic memory allocation in C using
malloc and free.

## Learning Objectives

- Understand automatic and dynamic memory allocation.
- Understand how malloc and free work.
- Know when and why to allocate memory dynamically.
- Check for memory leaks using Valgrind.

## Tasks

| File | Description |
|---|---|
| 0-create_array.c | Creates and initializes a character array |
| 1-strdup.c | Duplicates a string in allocated memory |
| 2-str_concat.c | Concatenates two strings |
| 3-alloc_grid.c | Allocates and initializes a 2D integer grid |
| 4-free_grid.c | Frees a 2D integer grid |

## Compilation

Compile using GCC with:

-Wall -Werror -Wextra -pedantic -std=gnu89

## Requirements

- Follow Betty coding style.
- No global variables.
- No more than five functions per file.
- Use only permitted standard library functions.
- Include all prototypes in main.h.
