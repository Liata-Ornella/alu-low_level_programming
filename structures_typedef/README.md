
# C - Structures, typedef

This project introduces structures and typedef in C.

## Tasks

- `dog.h`: Defines `struct dog` and the `dog_t` type alias.
- `1-init_dog.c`: Initializes a dog structure.
- `2-print_dog.c`: Prints the dog's information.
- `4-new_dog.c`: Creates a dog and copies its name and owner.
- `5-free_dog.c`: Frees a dog's allocated memory.

## Concepts

- Structures in C
- The `typedef` keyword
- Pointers to structures
- Dynamic memory allocation
- String copying
- Memory management

## Compilation

The project uses:

`gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
